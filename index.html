From a profile to object storage

The write path batches profiles into segments. Compaction turns small segments into larger blocks.

01 · CollectSDKs and collectors send profiles with labels, samples, and stacks.
02 · DistributeThe distributor routes incoming profiles to segment writers.
03 · Write a segmentSegment writers accumulate profiles in memory, then write a block.bin object.
04 · RegisterThe metastore indexes block metadata so readers can discover the data.
05 · CompactCompaction merges segments into larger, tenant-organized blocks.

Default synchronous ingestion waits for durable object storage and metadata registration. The metastore stores metadata, not the profile samples themselves.

04 /

The mental model to keep

TSDB ≠ sample storage

The TSDB index provides label-based lookup. It is not a Prometheus time-series sample store inside Pyroscope.

Parquet ≠ named stacks

Profile rows hold sample values and references to stack traces. Symbol data supplies the functions and locations behind those references.

One object ≠ read everything

Dataset metadata includes byte offsets. The query path can select relevant datasets rather than reading the entire block.
