# Pyroscope v2 storage demo

An interactive, static explainer of Pyroscope v2 storage: TSDB indexes, SymDB, Parquet, block metadata, and the query path.

**Live site:** https://simonswine.github.io/pyroscope-v2-storage-demo/

Open `index.html` directly in a browser. No build, dependencies, or backend required.

Diagrams and data are illustrative, not an exact I/O trace. Links to upstream documentation are included in the page. Independent educational demo with Grafana-inspired styling; not an official Grafana publication.

Published with GitHub Pages from the root of `main`.
